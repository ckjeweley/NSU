# 나라장터 발주계획·입찰·낙찰·물품목록·쇼핑몰 OpenAPI 통합 검색 시스템

공공데이터포털에서 활용승인 완료된 **조달청 5종 OpenAPI(REST)**를 연계하여 발주계획 분석 및 물품식별번호 기반 **회사명·제품명·연락처 소개 조회**를 수행하는 웹 서비스입니다.

## 1. 활용신청 승인 완료된 조달청 OpenAPI (5종)
1. **[승인] 조달청_나라장터 발주계획현황서비스** (`OrderPlanSttusService`)
2. **[승인] 조달청_나라장터 입찰공고정보서비스** (`BidPublicInfoService`)
3. **[승인] 조달청_나라장터 낙찰정보서비스** (`ScsbidInfoService`)
4. **[승인] 조달청_물품목록정보서비스** (`ThngListInfoService`)
5. **[승인] 조달청_나라장터쇼핑몰 품목정보 서비스** (`ShoppingMallPrdctInfoService`)

## 2. 사용법 및 활용 시나리오
- **1단계 (날짜 선택)**: 발주계획현황서비스 기준 조회 시작일~종료일 지정
- **2단계 (분석 종류 선택)**: 업무구분별 / 수요기관별 / 계약방법별 / 월별 추이 분석 차트 확인
- **3단계 (계약정보·식별번호 검색)**: 8자리 물품식별번호(예: `24891023`), 발주계획번호, 입찰공고번호 검색
- **4단계 (회사명, 제품명, 연락처 정보 조회)**: 낙찰정보·쇼핑몰품목정보·물품목록정보 API가 연계된 상세 소개 카드에서 회사명, 대표자, 제품명/규격, 담당자 연락처 확인
